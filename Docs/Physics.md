# 물리

Jolt Physics로 강체를 시뮬레이션한다.

- **바디**는 Jolt가 움직이는 강체 하나,
- **콜라이더**는 바디를 이루는 충돌 모양(상자, 구) 하나다.
- **동기화**는 틱마다 바디를 만들거나 지우고, 목표 위치·임펄스처럼 매 틱 바뀌는 값을 바디에 옮기고, 스텝 뒤 바디의 위치·회전을 Transform에 다시 쓰는 일이다.
- 바디는 한동안 거의 안 움직이면 **잠들고**(Jolt가 계산에서 뺀다) 힘이나 충돌이 오면 **깨어난다**.

| 클래스 | 역할 |
|---|---|
| `JoltRuntime` | Jolt가 프로세스에서 한 번만 초기화해야 하는 것(메모리 할당자, 타입 등록, 잡 시스템)을 묶어 소유한다 |
| `JoltWorld` | Jolt 시뮬레이션 하나. 바디·힌지·물 영역을 만들고 지우며, 스텝을 진행하고, "이 상자와 겹치는 바디는?" 같은 질의에 답한다 |
| `PhysicsScene` | 씬 하나의 물리. 동기화를 하고, 바디 id처럼 실행 중에만 있는 상태를 가진다 |

## JoltRuntime

- 프로세스에 하나만 만든다.
- 잡 시스템은 단일 스레드로, 같은 입력에 같은 결과를 내보닌다.

## JoltWorld

- 컴포넌트는 바디보다 오래 살고 바디는 중간에 새로 만들어지므로 Handle로 관리한다.
- 바디의 위치, 회전 기준점은 오브젝트 Transform이다.
- 충돌 레이어는 Static과 Moving(Dynamic과 Kinematic) 둘로, 움직이지 않는 것끼리는 부딪힐 일이 없으므로 Static-Static 쌍은 충돌 검사에서 제외한다. Query도 Moving만 확인한다.
- 물은 깨어 있는 Dynamic 바디에만 매 틱 부력과 저항을 주는 영역이다.(바디가 아니다.)

## PhysicsScene

- PhysicsScene은 물리가 실행 중인 상태(컴포넌트)를 의미한다.
- 모든 콜라이더는 자기부터 위로 올라가 처음 만나는 (활성화 상태의) RigidBody에 속한다.
- 바디는 처음 만들 때의 모양과 설정으로 고정되고, 콜라이더가 늘거나 줄면 바디를 새로 만든다. (이때 속도는 0이다.)
- 잠든 바디에는 힘을 주지 않으므로 저절로 깨지 않는다. 따라서 물 영역이 바뀌거나 사라지면 그 안에 있는 잠든 바디를 깨운다.
- 잘못된 값(음수 질량, 콜라이더 없음 등)은 동기화할 때마다 다시 검사한다.

## 컴포넌트

- `RigidBodyComponent`: 이 오브젝트가 바디다. Dynamic은 Jolt가 움직이고, Kinematic은 스크립트가 준 목표 위치로 움직이며, Static은 움직이지 않는다.
- `BoxColliderComponent`, `SphereColliderComponent`: 바디를 이루는 충돌 모양 하나.
- `HingeComponent`: 이 오브젝트의 바디를 자기 위치를 지나는 한 축 둘레로만 돌게 묶는 힌지다. 축의 위치는 만들 때 정해지고 오브젝트를 옮겨도 따라가지 않는다(설정 고정과 같은 이유다).
- `WaterVolumeComponent`: 이 오브젝트의 위치와 스케일이 물 상자 영역이다. 상자는 월드 축에 나란하고 회전은 무시한다.

## 주의

- 바디가 붙은 오브젝트의 조상이 비균등 스케일이라면 콜라이더 모양이 근사가 되고, 스텝 결과를 로컬 Transform와 동기화할 때도 틀어진다.
- Hinge의 콜라이더가 축에서 먼 작은 것 하나뿐이면 회전 관성이 너무 작아진다. (제약 솔버가 축 위치를 지키지 못한다.) 축까지 이어지는 막대 콜라이더를 하나 더 둔다.
