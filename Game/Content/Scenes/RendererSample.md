# RendererSample

Run `Game.exe -scene RendererSample` from the Game build output. The Game post-build step copies `Content` beside the executable. The fog markers use an untextured white material. The initial sky uses `galileo_cross.dds`. The model selector contains Alfa Romeo, Master, Tank, Aleksandr, Cannon, Cerberus, Shield, and USN Hornet in that order. Each model loads when first selected and its instance is reused afterward. Imported model materials stay independent, so edits in this sample do not change their source `.mat` files.

The three original models are in `Game/Content/Models/AlfaRomeo_1933`, `Master`, and `Tank`. Master and Tank use their complete skeleton prefabs. The additional models were copied from the class materials' `Data/PBR` directory into `Game/Content/Models/Aleksandr`, `Cannon_N`, `Cerberus+`, `SnW`, and `USN-Hornet`. Each copied directory contains its glTF file and the binary and image files referenced by that glTF. Selecting Tank's **Next clip** button cycles its stand, attack, and work animations.

Use the on-screen `−` and `+` buttons to select a model and material slot, edit BaseColor/Metallic/Roughness, switch MR and normal maps, control environment and shadows, play or pause animation, and configure fog. The `all slots` choice edits each material slot. The middle panel cycles six existing environment maps and adjusts directional light yaw, pitch, and intensity. Auto rotate has off, model, and camera orbit modes, with adjustable speed in degrees per second. Camera orbit looks toward the model display center and temporarily disables fly controls. The Hide UI button or `H` collapses all three panels, leaving the button available to restore them.

The left/right arrows also select models. `WASD`, Space and Shift move the camera when fly controls are active; right mouse drag rotates it. `F` restores the model view, `V` switches model/fog views, `P` pauses or resumes the selected animation, and `R` restores all sample defaults. The mouse wheel changes fly speed. Fog markers are identical untextured white spheres at four distances; show them and choose the fog camera view for comparison. Reset env + sun restores the initial map, brightness, light direction, intensity, and shadows.

Model registrations and their position, rotation, and scale corrections are in `RendererSample::Start()` in `Game/Source/Scripts/RendererSample.cpp`. Use `AddStaticModel` for a glTF mesh or `AddSkinnedModel` for a complete prefab containing its own skeleton, renderer, and Animator. List only compatible clips in a skinned model's registration. `PrepareMaterials` copies every renderer slot into uniquely named runtime materials. The engine generates default `.mat` files beside a glTF when it first loads one and no matching material files exist. `Game/Content/Models` is ignored by the repository's `.gitignore`, so these copied assets remain local unless that ignore policy is changed.

The sample uses the engine's existing Skybox, Fog and Light components. Brightness affects the sky background and IBL together; zero brightness removes their contribution. There is no public IBL bake-success query. Pausing animation holds its time and pose by using speed zero. The sample does not provide an animation application-off switch, seek, blending, Height Fog parameters, or per-object shadow controls.
